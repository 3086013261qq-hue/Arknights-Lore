# 《明日方舟》MVU 成熟网易云 + 正式悬浮窗继承规范 v1.0

> 本文件是交给“静静”使用咩咩制卡包·全栈组装时的强制运行时规范。
> **网易云与悬浮窗均不重新设计底层，直接继承我们在《亚空间演唱会 / Warhammer BanG！！》及后续卡中已经实机验证的成熟实现。**
> 本项目只替换《明日方舟》皮肤、曲目与显示字段，不得另造一套播放器或简化成普通小标签。

## 1. 网易云：只换歌与皮肤，不重写底层

成熟播放器固定使用网易云 outchain：

`https://music.163.com/outchain/player?type=2&id={track_id}&auto=0&height=66`

硬规则：

- 全卡始终只有 **1 个 iframe / 1 个网易云播放器实例**；
- `auto=0`，首次载入不强制自动播放；
- 点击曲目时只更新 `track_id` 并重载同一个播放器实例；
- 曲目列表来自 `manifest/mvu-music-playlist.v1.json`；
- 本轮只换成《明日方舟》/ 塞壬唱片曲目，不重写成熟播放器逻辑；
- 网易云 App 跳转只允许由玩家真实点击触发；
- App 优先，失败后走 HTTPS 网易云官方网页 fallback；
- 登录 / 会员播放只跳官方顶层页面处理；
- 不保存 Cookie、token、session、密码或登录凭证；
- 会员态无法透传到 outchain 时，提供官方 App / 官网播放入口，不破解、不代理；
- 网易云不可达、单曲下架、地区限制、iframe 报错均不得影响 MVU、世界书切卷、咩咩状态、干员页或悬浮窗；
- DOM / 楼层重绘后必须自动恢复单实例并重新绑定控件；
- 不允许复制第二个隐藏播放器解决重绘问题。

### 1.1 UI 皮肤

播放器外壳继续采用本项目的《明日方舟》/ PRTS 高保真视觉规范：硬边、斜切、编号、黑灰白、小面积黄强调。

禁止：

- 圆角网易云 App 卡片；
- 红色网易云主题覆盖整个 MVU；
- 新建第二套音频条；
- 为音乐额外建立剧情状态。

网易云原生 outchain iframe 本身可保留官方内容，外层包裹由 PRTS 风格容器负责视觉统一。

## 2. 正式悬浮窗：不是“迷你标签”

悬浮窗使用成熟独立前端运行时，必须挂载到 `document.body` 或等价的 body 级独立宿主，**不得绑定某一条消息 DOM**。

### 2.1 宿主与生命周期

- `position: fixed`；
- 高 `z-index`，但不得覆盖系统弹窗 / 必要宿主控制；
- singleton：任何时刻只能有一个悬浮窗；
- AI 楼层 / DOM 重绘后自动重新挂载并恢复；
- 不因切换 MVU 页面、切卷或消息更新而重复生成；
- 展开、折叠、关闭均只属于前端 UI，不写咩咩状态；
- 允许保存本次页面会话中的位置/展开态作为临时 UI 状态，但不得成为剧情事实。

### 2.2 手机端尺寸与安全区

- 宽度：`min(92vw, 420px)`；
- 最大高度：约 `70vh`；
- 内容超高时内部滚动，禁止把整页撑宽/撑高；
- 使用 `visualViewport` 与 `env(safe-area-inset-*)` 适配软键盘、刘海与底部手势区；
- 360 / 390 / 412 / 430px 宽手机均须实机检查；
- 横竖屏变化后重新夹取位置，始终保持在可视区域内。

### 2.3 拖拽

- 顶部标题栏 / 指定 drag handle 可拖拽；
- 手机使用 pointer/touch 事件，不依赖 hover；
- 拖动结束后将坐标 clamp 到当前 visual viewport；
- 禁止拖到屏幕外找不回来；
- 点击按钮/滚动内容时不得误触发拖拽。

### 2.4 三态

正式悬浮窗至少支持：

1. **展开**：完整 PRTS PLAYER WINDOW；
2. **折叠**：保留窄标题条 / 小型 PRTS 按钮；
3. **关闭**：主体隐藏，但保留一个不挡正文点击的恢复入口。

收起 / 关闭后宿主空白区域必须 `pointer-events:none` 或等价处理，**禁止透明层挡住聊天正文或选项点击**。

## 3. 悬浮窗内容

悬浮窗定位为 `P.R.T.S. // PLAYER WINDOW`，是全局快速查看与控制层，不是第二个完整 MVU。

### 3.1 PLAYER STATUS

只读咩咩现有 `<status>`，展示已有字段：

- 当前时间；
- 当前地点；
- 当前世界 / 剧情阶段；
- 当前任务 / 进度（若 `<status>` 已提供）。

禁止为这些字段建立 MVU 持久副本。

### 3.2 CURRENT OPERATION

- 从 73 个 `ARKNIGHTS_TIMELINE:*` 中读取唯一 `enabled=true`；
- 显示当前卷 ID / 标题 / ACTIVE；
- 这里只读；
- 切卷必须回到 `OPERATIONS ARCHIVE` 点击 `ENTER / 进入记录`，悬浮窗不提供偷偷切卷的第二入口。

### 3.3 AUDIO

- 显示当前网易云曲名；
- 提供播放区展开 / 收起或打开 AUDIO TERMINAL 的快捷入口；
- 继续控制同一个成熟 outchain iframe，不生成第二播放器；
- 音乐报错只在本区域提示，不影响 PLAYER STATUS。

## 4. 明日方舟高保真皮肤

悬浮窗也必须遵循 `docs/mvu-arknights-visual-fidelity-v1.md`：

- 黑灰白基底 + 小面积罗德岛黄；
- 斜切、缺角、短线、编号、英文微字；
- `P.R.T.S. // PLAYER WINDOW` 标题；
- 展开态有明显前后景层级；
- 折叠态仍然像明日方舟终端控件，而不是网页圆形悬浮球；
- 不使用玻璃拟态、霓虹光晕、大圆角。

## 5. 与主 MVU 的边界

悬浮窗不得：

- 成为第二状态源；
- 复制世界书正文；
- 维护 `_current_volume`；
- 修改 `<world_timeline>`；
- 自动推进剧情；
- 自动切卷；
- 因音乐错误导致整个 UI 报错；
- 因 DOM 重绘生成多个实例。
