# 明日方舟地点世界书生产规范 v1.0

## 1. 定位

地点条目属于咩咩制卡包·全栈的卡内世界书，与远程剧情时间线、角色正文、媒体层严格分离。

正式源路径：`worldbook/locations/*.md`。

## 2. 原生格式

每个地点只使用咩咩全栈原生核心设定标签：

```text
<核心设定:地点名>
...
</核心设定:地点名>
```

禁止新增 `<location>`、`<place>` 等私有标签。

## 3. 必备字段

每个正式地点至少包含：
- 类型
- 国家/地区
- 上级地点
- 定位
- 空间与环境
- 社会与功能
- 主要组织/势力
- 关键人物关联
- 剧情关联
- 时间状态
- 知识迷雾
- RP场景特征
- 互动约束
- 触发词
- 来源锚点

## 4. 内容原则

- 只写会影响剧情、行动、人物判断与场景表现的地点事实。
- 不为了补字段杜撰建筑尺寸、人口、距离、武器数量、隐藏设施或历史细节。
- 国家级概念继续由 `worldbook/settings/02_国家与政治秩序.md` 负责；地点卡只写具体城市、城区、设施、舰船、遗址与特殊区域。
- 城市总卡与子地点可以并存，但不得重复整段国家史或城市史。
- 同一地点跨时代变化写入同一条目的“时间状态”，避免旧城/新城重复加载。
- 普通 NPC 只能知道其身份、组织、时代与经历合理允许知道的信息；机密设施、深层真相和未来状态不得无条件泄漏。
- 游戏关卡格、敌人数值、部署机制、Boss机制不写成世界内硬事实。
- 场景必须去玩家中心化：地点中的政府、组织、居民、经济、交通与冲突不会围绕 {{user}} 停摆。

## 5. 来源优先级

1. 游戏内剧情与官方公开资料；
2. PRTS 等公开资料站用于定位与查漏；
3. 已封版仓库主线/SideStory时间线与正式角色/核心设定上下文。

如事实无法可靠确认，则保守写法或省略，不自行补完。

## 6. 批次与 QA

计划地点总数：85。

- Batch 01：A01-A15 + B01-B10，共25个。
- 后续批次按已封版地点总表继续。

每批必须检查：标签闭合、地点名唯一、文件唯一、manifest登记、国家/上级地点一致性、知识迷雾、时间状态、来源锚点，以及未修改封版时间线/人物/萌点/武器/世界设定/媒体。
