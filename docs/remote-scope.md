# 远程层职责边界

## 结论

`Arknights-Lore` 只承载体量过大的剧情时间线。

## 远程内容

- 主线剧情时间线
- 活动与支线剧情时间线
- 角色个人剧情时间线（仅剧情事件链，不是角色档案）
- 剧情索引、版本信息与按需加载协议

## 卡内内容

以下内容直接保留在咩咩全栈角色卡世界书中，不通过本仓库远程加载：

- 角色条目
- 地点条目
- 核心设定条目

原因：这些资料体量可控、触发频繁，随卡内世界书常驻或关键词触发比远程加载更稳定。

## 运行原则

远程运行时只根据当前剧情进度选择所需时间线块，不以当前角色或地点去远程抓取人物/地点档案。人物、地点与设定事实由卡内世界书提供。
