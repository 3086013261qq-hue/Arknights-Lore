# 明日方舟远程剧情时间线生产规范 v1.0

> 目标：为 `Arknights-Lore` 构建可按剧情进度远程加载、可持续扩展、可审计的正式剧情时间线。
> 适配：咩咩制卡包·全栈与现有咩咩预设；禁止修改预设本体。

## 1. 资料优先级

1. 游戏内正式剧情、官方公开资料。
2. PRTS：用于关卡定位、剧情原文查核、泰拉年表、人物行动与事件结果核验。
3. 《明日方舟剧本小说》：仅用于时间顺序、日期锚点、场景衔接和时间间隔辅助；与官方/PRTS冲突时以前两者为准。
4. 其他资料只可作为查漏提醒，不可直接成为正式正文来源。

正式时间线必须重新组织、压缩与改写，不直接复制大段游戏对白、Wiki正文或小说化文本。

## 2. 总体拆分

远程剧情分为三层：

- `timeline/main/`：主题曲主线章节。
- `timeline/side/`：SideStory、插曲、别传及与主线强关联活动。
- `timeline/operator/`：角色个人剧情事件链，仅写事件，不重复角色档案。

主线章节当前正式范围：序章/第00章至第17章。

## 3. 主线文件粒度

每个主题曲章节独立成一个稳定文件：

- `timeline/main/main-00.md`
- `timeline/main/main-01.md`
- ...
- `timeline/main/main-17.md`

禁止把多个大型章节合成一个超大文件。

与主线直接相连的 SideStory 不复制进主线文件；主线只保留 `关联前置/关联插曲` 指针，正式内容放在 `timeline/side/`。

## 4. 正式事件格式

每章统一使用：

```text
<world_timeline id="main-XX" title="章节名">
时间范围:
时间精度:
主地点:
前置:
后置:
关联剧情:

事件A:
- 时间:
- 地点:
- 参与者:
- 起因:
- 过程:
  A1.
  A2.
  A3.
- 结果:
- 状态变化:

事件B:
...

章节结束状态:
- 
- 
</world_timeline>
```

### 颗粒度规则

- `事件A/B/C`：可以独立改变人物、势力、任务或地点状态的主要事件。
- `A1/A2/A3`：主要事件内部的连续动作与因果步骤。
- 不以“每关一事件”机械拆分；多个关卡若属于同一连续行动，可合并为同一事件组。
- 重大死亡、阵营变化、俘虏/脱离、核心情报获得、城市状态变化必须单独记录。
- 战斗只写剧情上有意义的目标、转折和结果，不写游戏机制与敌人数值。

## 5. 时间规则

时间字段分四种精度：

- `exact`：官方/PRTS可核到具体年月日，必要时可到时分。
- `day`：可核到具体日期但无精确时刻。
- `month`：只能核到年月。
- `relative`：只能确认相对顺序，例如“切尔诺伯格撤离后不久”。

硬规则：

- 能核到具体日期时必须写具体日期。
- 无可靠证据时禁止为了格式虚构日/月。
- 暂未核实的时间写 `待核`，同时保留可验证的相对锚点。
- 相邻事件必须保持连续，不能出现无解释的时间倒流。
- 回忆、历史事件、梦境、源石内化宇宙等非当前时序内容必须明确标记为 `回溯/异时态`，不得与当前主线时间混排。

## 6. 强关联 SideStory 锚点

新版曲谱中与主题曲直接串联的剧情，主线索引必须保留阅读/因果锚点，但内容仍放 `timeline/side/`：

- `生于黑夜`
- `遗尘漫步`
- `照我以火`
- `巴别塔`
- `追迹日落以西`
- `人们，我们`

后续如官方曲谱增加新的直接关联章节，更新索引但不破坏既有稳定 ID。

## 7. 状态与因果

每个主事件至少记录以下变化中实际发生的项目：

- 人物：生死、伤势、失踪、俘虏、脱队、入队、身份揭示。
- 势力：联盟、敌对、控制区变化、领导者变化。
- 地点：毁坏、占领、撤离、移动城市状态。
- 情报：新获得的关键事实、误导被纠正、秘密公开。
- 任务：开始、推进、失败、完成、改目标。

上一剧情块的 `章节结束状态` 应成为下一块的有效前置，不重复大段叙述。

## 8. QA

每章完成后必须检查：

1. 来源 QA：关键事实可被官方/PRTS支持。
2. 时间 QA：日期、时刻、回溯与当前时序不冲突。
3. 因果 QA：起因→行动→结果连续，无凭空跳转。
4. 人物 QA：生死、位置、所属、伤势不与已完成章节冲突。
5. SideStory QA：强关联剧情有锚点，但正文不重复拷贝。
6. 去原文 QA：不保留大段游戏对白或百科正文。
7. 体积 QA：每个远程块只保留运行时需要的剧情事实。

## 9. 当前施工顺序

1. 建立 `main-story-order.v1.json` 总骨架。
2. 主线第一批：00–03（觉醒）。
3. 主线第二批：04–08（幻灭），同时建立《生于黑夜》锚点。
4. 主线第三批：09–14（残阳），同步建立《遗尘漫步》《照我以火》《巴别塔》锚点。
5. 主线第四批：15–17（裂变），同步建立《追迹日落以西》《人们，我们》锚点。
6. 主线通过后，再批量制作其他 SideStory 与角色个人剧情。
