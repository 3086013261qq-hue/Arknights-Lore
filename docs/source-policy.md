# 资料来源与重写规范

## 定位

本仓库只保存为咩咩全栈角色卡重新整理后的轻量资料，不保存外部整合卡、剧情包、小说化文本的原始全文。

## 当前参考源

1. `Ark_v0.3`：角色、地点、国家、组织、种族与核心设定的高密度索引与查漏参考。
2. `7.20最新整合剧情世界书`：主线、活动与支线的事件骨架、节点顺序与发生逻辑参考。
3. `明日方舟剧本小说`：主线场景级校对参考，用于核对人物行动、场景、对白归属与因果。
4. `直到大地变成一颗酸橙`：角色个人剧情与人物关系的补充参考。

## 使用规则

- 外部资料仅用于检索、对照、校验和查漏。
- 正式入库内容必须重新组织、压缩和改写，不直接复制大段原文。
- 主线优先采用“剧情骨架 + 场景校对”的双源交叉方式。
- 活动剧情在缺少第二校对源时，必须保留来源不确定性，不把整理者推断写成官方硬事实。
- 对人物动机、时间顺序、因果关系存在冲突时，先标记待核，不自行补完。
- 对白只保留剧情理解所必需的极短关键句，避免将原作逐句文本作为资料主体。

## 正式资料目标

正式世界书只维护四类内容：

- 时间线
- 角色
- 地点
- 核心设定

其余内容仅在确有必要时并入上述四类，不额外扩张百科式目录。
