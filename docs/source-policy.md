# 资料来源与重写规范

## 定位

本仓库只保存为咩咩全栈角色卡重新整理后的远程剧情时间线，不保存外部整合卡、剧情包、小说化文本的原始全文。

角色、地点与核心设定虽然同样需要重新整理，但它们属于卡内世界书，不作为本仓库远程运行时资源。

## 当前参考源

1. `Ark_v0.3`：角色、地点、国家、组织、种族与核心设定的高密度索引与查漏参考；主要服务于卡内世界书制作。
2. `7.20最新整合剧情世界书`：主线、活动与支线的事件骨架、节点顺序与发生逻辑参考；是远程时间线重写的重要骨架源。
3. `明日方舟剧本小说`：主线场景级校对参考，用于核对人物行动、场景、对白归属与因果。
4. `直到大地变成一颗酸橙`：角色个人剧情与人物关系的补充参考；其中可核实的个人剧情事件可转写为 `timeline/operator/` 时间线。

## 使用规则

- 外部资料仅用于检索、对照、校验和查漏。
- 正式入库时间线必须重新组织、压缩和改写，不直接复制大段原文。
- 主线优先采用“7.20剧情骨架 + 剧本小说场景校对”的双源交叉方式。
- 活动剧情在缺少第二校对源时，不把整理者推断写成官方硬事实；存在疑点先进入 QA 待核。
- 对人物动机、时间顺序、因果关系存在冲突时，先标记待核，不自行补完。
- 对白只保留剧情理解所必需的极短关键句，避免将逐句文本作为资料主体。

## 正式资料分工

### 远程仓库
- 时间线

### 卡内世界书
- 角色
- 地点
- 核心设定

二者共同服务于同一张咩咩全栈角色卡，但运行时职责严格分离。
