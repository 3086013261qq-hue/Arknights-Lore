# Worldbook

本目录保存《明日方舟》角色卡中需要长期维护、可直接返修的正式世界书源稿。

## 角色正式源

- `operators/<干员名>.md`：463 名干员的唯一正式最新版；文件内同时保存 `<角色名character>` 与 `<核心设定:角色名·能力>`。
- `npcs/<NPC名>.md`：精选核心剧情 NPC 的正式源。
- `operator-moe.v1.json` 与 `operator-moe/`：463 名干员的兽化/非人体征萌点覆盖层。
- 角色返修直接修改正式文件，不回头修改历史 Batch。

## 世界设定正式源

- `settings/*.md`：咩咩制卡包·全栈核心设定条目，使用 `<核心设定:条目名> ... </核心设定:条目名>`。
- `manifest/world-settings.v1.json`：设定条目索引、触发关键词与高剧透分层。
- 前文明深层真相独立分片，建议按剧情阶段或关键词启用，避免NPC获得超出自身权限的知识。

## 与 build / timeline / media 的关系

- `build/character-worldbook/` 仅保存施工、QA、历史样板和批次记录，不是长期正文事实源。
- `timeline/` 保存已封版剧情时间线；世界设定不得自行覆盖事件顺序。
- `media/mvu/operators/` 为封版媒体，世界书返修不得重新生成或重命名媒体。
