# 明日方舟世界设定 · 前文明与深层真相
# 本文件属于高剧透核心设定；装卡时建议按剧情阶段或关键词触发，避免早期角色无条件知晓。

<核心设定:前文明>
类型:高剧透历史真相
定义:现今泰拉文明之前曾存在技术水平远超当代的前文明，其遗留工程、设施和存续计划深刻影响了源石、海洋、天空以及罗德岛相关历史。
核心事实:
- 前文明拥有远超现代泰拉的生命工程、信息技术、行星工程和大型设施。
- 前文明最终面对足以摧毁文明的星外/宇宙级威胁，并启动多条不同的文明存续计划。
- 当代绝大多数泰拉人并不知道这些真相。
知识边界:
- 前文明信息属于极高层级秘密，只有少数角色、设施记录和重大剧情节点能够逐步揭示。
</核心设定:前文明>

<核心设定:文明存续计划>
类型:高剧透历史真相
定义:前文明在灭亡前启动了多条相互独立的文明存续路线，希望在灾难之后保存生命、知识或文明延续的可能。
核心事实:
- 已知方向包括源石计划、保存者相关计划、海洋方向的深蓝之树等不同尝试。
- 各计划目标都与“文明如何跨越灭亡”有关，但方法、代价和最终结果并不相同。
运行规则:
- 不把不同计划的设备、人员和权限混为同一套系统。
- 角色知道某一条计划，不代表自动知道全部前文明真相。
</核心设定:文明存续计划>

<核心设定:源石计划>
类型:高剧透核心设定
定义:源石计划是前文明的文明存续方案之一，由“预言家”与普瑞赛斯深度参与，试图利用源石的信息承载与扩张性质保存文明。
核心事实:
- 源石并非仅仅是自然能源矿物，其深层性质与前文明设计、信息保存和文明延续有关。
- 普瑞赛斯更倾向让文明被源石体系内化保存；预言家后来对新生文明产生不同判断。
- 当代泰拉围绕源石形成的工业、矿石病和社会体系，是这一古老计划在漫长历史中的现实后果之一。
知识边界:
- 普通角色不会知道源石计划的真实目的。
- 不把“源石计划”简化为制造矿石病的恶意实验。
</核心设定:源石计划>

<核心设定:博士·预言家身份>
类型:高剧透人物真相
定义:博士的真实历史身份与前文明“预言家”有关，是源石计划和文明存续讨论中的关键参与者之一。
核心事实:
- 博士并非当代泰拉普通意义上的出生者，其身体和记忆经历过漫长休眠与重大改变。
- 巴别塔时期的博士已失去大部分前文明生活的连续性，却仍展现出极高战略与研究能力。
- 特蕾西娅事件后，博士再次失去关键记忆，形成主线开始时的状态。
本卡身份硬规则:
- 博士是 `worldbook/npcs/博士.md` 对应的独立NPC；`{{user}} != 博士`。
- 原作剧情、时间线与世界书中的“博士 / Doctor / 预言家（博士语境）”默认指向博士NPC，不得自动替换为{{user}}。
- 博士的前文明身份、石棺与失忆史、巴别塔经历、罗德岛创始人/高层身份、博士级PRTS权限以及与阿米娅、凯尔希、特蕾西娅、普瑞赛斯、W等人的既有关系，只属于博士NPC。
- {{user}}是与博士并存的独立人物；只有玩家自己在卡内建立的身份、关系和经历才属于{{user}}。
- 时间线中“博士指挥/行动/被营救”等事实仍由博士NPC承担，不得为了玩家中心化转移给{{user}}。
知识边界:
- “博士=预言家”属于最高级别剧透；除明确知情者外，NPC不得凭常识得知。
- 身份隔离的完整运行规则见 `docs/player-doctor-identity-separation-v1.md`。
</核心设定:博士·预言家身份>

<核心设定:普瑞赛斯与PRTS>
类型:高剧透核心设定
定义:普瑞赛斯是前文明源石计划的重要参与者，与博士关系极深；PRTS系统与她的名字、权限和前文明遗产存在直接联系。
核心事实:
- 普瑞赛斯与博士对文明应如何借助源石存续存在根本理念分歧，但两人的关系并非简单敌对。
- PRTS承担罗德岛舰上的重要信息、管理与权限功能，并保留前文明层级的数据痕迹。
- 普瑞赛斯能够通过源石及相关系统观察、干预部分现实，但其能力受具体剧情条件限制。
运行规则:
- 不把PRTS写成无所不能的AI，也不默认所有罗德岛成员知道其前文明来源。
- 博士相关PRTS权限不得自动赋予{{user}}。
</核心设定:普瑞赛斯与PRTS>

<核心设定:石棺与保存者>
类型:高剧透前文明设施
定义:“石棺”是前文明遗留的生命维持/修复与长期保存设施体系之一，切尔诺伯格石棺与保存者计划历史相关。
核心事实:
- 石棺可以对特定前文明个体产生维生、修复和休眠作用，但对当代泰拉种族可能产生不同结果。
- 博士曾在石棺中长期休眠。
运行规则:
- 石棺不是通用复活机，也不是任何伤者进入后都能痊愈。
- 博士的石棺经历不属于{{user}}的默认背景。
</核心设定:石棺与保存者>

<核心设定:罗德岛本舰>
类型:高剧透设施
定义:罗德岛制药的陆行舰并非普通现代企业从零建造的舰船，其本体与前文明遗产及后来巴别塔、罗德岛的历史相连。
核心事实:
- 本舰内部存在远超普通移动平台历史的设施、权限和封闭区域。
- 当代罗德岛长期以现代工程手段维护、改造和使用舰船，但并未完全掌握所有深层结构。
运行规则:
- 舰内未知区域、旧系统和最高权限不向普通干员开放。
- 不把罗德岛本舰等同于整座移动城市；它是大型陆行舰与组织总部。
</核心设定:罗德岛本舰>

<核心设定:伐木工与星外灾难>
类型:最高剧透宇宙背景
定义:前文明灭亡与被称作“伐木工”的星外文明/灾难性力量有关，其威胁尺度超出当代泰拉国家战争。
核心事实:
- 前文明的多条存续计划正是在这一灭绝级压力下产生。
- 当代泰拉绝大多数人不知道该威胁存在。
运行规则:
- 不把“伐木工”当作随时会在普通剧情中出现的常规敌军。
- 在未进入相关深层剧情前，该信息只作为后台世界真相存在。
</核心设定:伐木工与星外灾难>
