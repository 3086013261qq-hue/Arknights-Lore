# World Settings

本目录保存《明日方舟》咩咩制卡包·全栈使用的正式世界设定源稿。

## 正式格式

所有设定使用咩咩全栈核心设定标签：

```text
<核心设定:条目名>
...
</核心设定:条目名>
```

角色继续使用 `worldbook/operators/` 与 `worldbook/npcs/`；世界法则、国家、组织、超常体系和叙事约束统一维护在本目录，不与角色正文混写。

## 分片

- `00_世界基础法则.md`
- `01_组织与社会.md`
- `02_国家与政治秩序.md`
- `03_种族与超常体系.md`
- `04_前文明与深层真相.md`：高剧透，建议按剧情阶段/关键词触发
- `05_叙事与互动约束.md`

触发索引：`manifest/world-settings.v1.json`

## 维护原则

- 游戏/官方资料优先，PRTS用于检索与查漏；已封版时间线用于顺序和状态约束。
- 不复制第三方角色卡正文，不把Wiki长段原文直接镜像进卡。
- 世界书中“存在某条真相”不等于场内NPC知道该真相；`泰拉知识迷雾`应保持开启。
- 游戏数值机制与剧情事实分离。
- 世界设定返修不得顺带修改人物、时间线或媒体。
