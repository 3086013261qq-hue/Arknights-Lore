# Roughcard Builder v2.6

Implementation bundle for the frozen v2.6 three-source roughcard pipeline.

Runtime source bundle is distributed as the PC ZIP attachment for local testing. The bundle contains modular Python source under `tools/roughcard_v26/`, Windows launcher, requirements, config, and local-only cache/raw-source rules.

Before full build, run the five-character validation set: 能天使、银灰、塞雷娅、斯卡蒂、莫斯提马.

Local-only directories: `raw-source/`, `.cache/`, `.models/`.
