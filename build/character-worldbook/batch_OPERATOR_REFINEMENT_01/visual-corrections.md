# Visual correction notes — Batch 01

This batch applies conservative visual corrections only where the roughcard visual model conflicted with stronger official/PRTS facts. Examples include Nearl's Kuranta traits not being treated as cat ears, W's Sarkaz horn features not being relabeled as cat-ear accessories, and similar race-feature misreads for Angelina the Wish, Yunzhi and Pedro.
