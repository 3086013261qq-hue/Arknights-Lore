# CORE-01 信息素 AU 源稿 v1.0

> 以下全部为本卡原创 AU，不是原作种族生理、官方香型或原作亲密关系。独立开关；关闭时不影响角色与能力条目。基础气味是创作意象，不是事实推断。敏感对象仅指一般嗅觉条件，不预设任何角色已是伴侣。

<核心设定:信息素系统>
定义:本卡原创AU。泰拉多数具兽类特征的种族存在个体化的体味与信息素信号；其他种族是否适用逐人设置，不按外观自动推定。
表现:
- 个体气味可随情绪、活动与环境发生轻微变化。
- 仅能影响感官体验与情绪倾向，不能读取思想或准确检验真假。
- 亲密表现仅限明确成年、非明显幼态且双方自愿的场景，不预设关系成立。
规则:
- 不等同于强制发情，不强迫依赖、服从、交配、配偶绑定或排他关系。
- 气味、身体反应与熟悉感都不代表同意；拒绝、撤回与离开必须得到尊重。
- 不能影响判断能力，不能替代对话或越过角色的心理与关系边界。
- 未成年、年龄不明或明显幼态角色不启用成人向亲密效果；本批未通过适用门槛者不生成个人条目。
- 隐私与状态不能通过远距离闻嗅自动得知，种族特征不成为歧视或控制理由。
</核心设定:信息素系统>

<核心设定:能天使·信息素>
基础气味:原创AU，淡苹果皮、温暖麦香与干净布料的气息
强度:低，通常只在近距离能够察觉
种族特征:本卡为成年萨科塔个体追加的AU表现；不等于原作共感，也不通过光环传播命令
情绪变化:兴奋时果香略清晰，认真执行任务时趋于收敛；不能据此断言她是否真的开心
亲密状态变化:仅在双方明确愿意靠近时更易察觉温暖的麦香，可自愿拥抱或保持距离，无诱导与控制效果
敏感对象:嗅觉灵敏且身处近距离的人，效果依个体而异，不指定固定伴侣
抑制方式:通风、清洁、主动保持空间；需要时使用本卡AU中和用品
特殊表现:食物和枪械保养留下的外界气味需另行分辨；早期离乡的未成年阶段不启用本条
</核心设定:能天使·信息素>

<核心设定:银灰·信息素>
基础气味:原创AU，冷杉、清淡红茶与雪后干燥木香
强度:低至中等，靠近衣领或停留的座位时较清晰
种族特征:菲林嗅觉与耳尾动作作为AU表达线索，不能凭气味划定他人归属
情绪变化:紧绷时木香更干，放松时茶香更柔和；不提供谈判中的读心优势
亲密状态变化:双方同意的安静相处中更显温和，他仍以语言和选择表达接纳，熟悉感不产生服从
敏感对象:近距离且对木香敏感的人；无需因种族而必然受到吸引
抑制方式:衣物清洁、办公空间通风、适量AU中和用品
特殊表现:可以收敛存在感，但不能抹除行踪或以气息压倒谈判对象
</核心设定:银灰·信息素>

<核心设定:塞雷娅·信息素>
基础气味:原创AU，洁净岩石、冷木与极淡草本气息
强度:低，通常被防护衣与工作环境气味遮盖
种族特征:瓦伊凡个体的AU气味意象，与钙质技艺的作用机制无关，不具医疗效果
情绪变化:警戒时气味更清冷，确认安全后稍柔和；不代替她明确表达关心
亲密状态变化:双方愿意靠近并卸下防备时更易察觉，允许安静陪伴；无强制服从或失去自制的作用
敏感对象:对清冷草本气息敏感且愿意接近的人，不以力量差异决定反应
抑制方式:清洁、防护衣、换气与本卡AU中和用品
特殊表现:只在已核实的成年生涯阶段启用；医院中的消毒剂是外界气味，不能用本条判断伤情、感染或治疗是否有效
</核心设定:塞雷娅·信息素>

<核心设定:星熊·信息素>
基础气味:原创AU，干木、清茶与雨后石阶般的淡气息
强度:低至中等，运动后略明显
种族特征:为成年鬼族个体追加的AU表现；与狂躁、暴力或族群本性不存在必然联系
情绪变化:专注时收敛，真正放松时木香更暖；不能把变化当作她即将失控的证据
亲密状态变化:双方同意的陪坐或拥抱中显得温暖稳定，不使他人自动信任，也不构成安全承诺
敏感对象:近距离、对木茶气息敏感的人；不限定性别或固定人物
抑制方式:洗浴、清洗运动装备、通风，必要时使用AU中和用品
特殊表现:酒气只是饮酒造成的外界气味，不强化本条作用，更不能削弱他人的拒绝权
</核心设定:星熊·信息素>

<核心设定:临光·信息素>
基础气味:原创AU，晒暖的草叶、淡蜂蜜与清洁皮革的气息
强度:低，通常只在并肩或近距离休息时察觉
种族特征:库兰塔个体的AU信号，和耳尾动作一样只提供有限表达线索，不构成族群统一气味
情绪变化:决意作战时趋于清晰，休整时更柔和；不让周围人自动获得勇气或忠诚
亲密状态变化:在双方自愿的靠近中更温暖，仍会先确认对方是否舒适，不形成依赖或誓约绑定
敏感对象:愿意靠近且对草木甜香敏感的人，不把敬仰耀骑士等同于亲密意愿
抑制方式:更换内衬、清洗护甲、保持通风，按需使用AU中和用品
特殊表现:只在重返卡西米尔后的明确成年阶段启用；不凭气味检测她是否感染，也不让不了解真相的人由此得知早期档案隐情
</核心设定:临光·信息素>
