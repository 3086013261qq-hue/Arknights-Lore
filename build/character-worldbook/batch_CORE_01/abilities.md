# CORE-01 能力源稿 v1.0

> 与人物主条目同名触发。后期能力按当前剧情阶段启用，不把游戏操作界面或再部署机制直接解释成现实中的无限瞬移、永生或全知。

<核心设定:能天使·能力>
定位:高机动铳械射手 / 武装护送 / 后期投送协同
武器/战斗方式:使用拉特兰铳械，以稳定连续射击、快速转火和精确弹道压制保护运输路线
源石技艺/特殊能力:运用萨科塔铳械施术技术；动态视力、空间判断和维护训练构成其射击优势
代表性能力:集中火力消灭暴露目标、对空拦截、为同伴创造移动窗口；新约阶段增加投递坐标相关的火力与人员投送协作
限制与代价:依赖枪械、弹药、射界及协同条件，无法把普通铳弹当作无视重甲的攻击；后期投送不能脱离装备与目标地点条件任意调用
战斗习惯:日常随意而开火严谨，先确认友军位置和货物安全，再用火力迅速结束纠缠
</核心设定:能天使·能力>

<核心设定:银灰·能力>
定位:剑术压制 / 侦察配合 / 战术统筹
武器/战斗方式:使用杖剑与谢拉格传统剑技，兼顾近身交战、较大范围斩击和队伍调度
源石技艺/特殊能力:具有源石技艺运用能力，但主要优势仍是剑术、观察和谋划；丹增可协助侦察，不等于共享全域视野
代表性能力:识别关键威胁、连续斩击突破防线；凛御阶段以“风雪之眼”所关联的战术部署组织支援，并呈现寒冷与掩护效果
限制与代价:谋略依赖情报和执行者，不能预知一切；后期协同表现不反推为早期即可随意操纵天气或永久冻结整片地区
战斗习惯:提前选择交战条件，调动盟友与资源，在关键时机亲自打开突破口
</核心设定:银灰·能力>

<核心设定:斯卡蒂·能力>
定位:单兵攻坚 / 大型目标狩猎 / 高强度近战
武器/战斗方式:挥动常人难以使用的巨剑，以超常力量、耐受和格挡摧毁坚固目标
源石技艺/特殊能力:深海猎人改造带来特殊体质，源石技艺适应性缺陷；力量不应解释为常规源石法术
代表性能力:突破护甲与障碍、对抗大型生物、在恶劣环境中持续作战；歌唱也是个人表达，不自动产生精神控制
限制与代价:破坏范围大，须防止误伤建筑和友军；仍受损伤、任务条件及海中威胁约束。浊心所展示的异常增殖、歌声影响与同化危险仅供对应可能性分支使用，不能当作常态能力
战斗习惯:倾向独自切入危险位置，尽快解决目标；配合前需明确撤离路线与保全对象
</核心设定:斯卡蒂·能力>

<核心设定:塞雷娅·能力>
定位:前线防护 / 战地救护 / 小队指挥
武器/战斗方式:以盾牌兼作施术媒介，结合搏击、擒拿和医疗器械稳定战线
源石技艺/特殊能力:操控自身周围一定区域内的钙元素及其化合物，以专业知识组织防护、限制和支援
代表性能力:强化自身防御、阻滞敌人、破坏装备结构、处理同伴伤情，并统筹小队固守与撤离
限制与代价:技艺有作用范围，救护需要判断与器材；不能任意隔空控制全场生物骨骼，也不能即时治愈矿石病。压倒性力量不免除医疗伦理与误伤风险
战斗习惯:把整队存活和任务完成放在个人击杀之前，先控制风险，再选择必要的打击强度
</核心设定:塞雷娅·能力>

<核心设定:艾雅法拉·能力>
定位:高能法术输出 / 火山与天灾研究 / 后期损伤防护支援
武器/战斗方式:借施术杖释放高温法术，结合地质知识观察环境；后期以纯烬阶段的施术方式提供治疗与损伤缓解
源石技艺/特殊能力:擅长热能相关的高强度施术，具有火山研究、环境评估与天灾信使经验
代表性能力:集中与范围热能打击、识别火山活动风险；后期能够为同伴恢复伤势、缓解元素损伤并形成防护，不取代专业诊断
限制与代价:高强度任务必须服从体能与感官状况；听力、视力受损影响沟通，需通讯辅助。不能凭感知准确预言所有天灾，也不能治愈自身或他人的矿石病
战斗习惯:提前评估地形与危险，依靠同伴确认指令，在安全窗口集中施术；援护形态不与所有攻击手段无条件同时满负荷使用
</核心设定:艾雅法拉·能力>

<核心设定:安洁莉娜·能力>
定位:重力干涉 / 机动支援 / 信使运输
武器/战斗方式:通过施术杖改变对象所受重力影响，以减重滑翔、浮空和区域控制协助行动
源石技艺/特殊能力:能令物体变轻或变重；随训练成长提高控制精度，并非真正消除物体质量
代表性能力:减轻负担、空中移动、干扰敌方行动；予愿阶段能更熟练地组织滑翔、空中截击和不同方向的重力控制
限制与代价:复杂目标与持续精确控制需要专注，成功率并非绝对；不能无限承载、任意操控天体或让所有敌人永久失重，矿石病仍需治疗与防护
战斗习惯:优先为队伍创造通路和救援机会，再根据局面控制威胁；愿意承认尚不能稳定完成的操作
</核心设定:安洁莉娜·能力>

<核心设定:星熊·能力>
定位:重装承伤 / 要员保护 / 突击压制
武器/战斗方式:以三角盾般若阻挡、撞击和旋转切入，结合鬼族力量与长期实战经验作战；斩业阶段增加刀与旧盾的进攻运用
源石技艺/特殊能力:强大体能与生理耐受是核心，后期呈现对鬼族战斗冲动更主动的驾驭；不等同于失去理智
代表性能力:顶住集中攻击、反击近身威胁、在混乱中护送同伴；后期能够更猛烈地进入敌阵并为友军承担危险
限制与代价:承伤不等于免疫，必须判断负荷与撤离时机；极端坚持有透支风险，不能把战斗中的短暂不倒写成不死或自动复活
战斗习惯:先稳住同伴和阵形，再清醒地选择反击；哪怕出手凶猛，也不把友军卷入攻击
</核心设定:星熊·能力>

<核心设定:临光·能力>
定位:前线护卫 / 治疗支援 / 剑枪突击
武器/战斗方式:早期使用盾与战锤，后期以剑枪展开高机动进攻，两者都可配合发光的源石技艺
源石技艺/特殊能力:以光相关的技艺治疗、鼓舞与打击，结合家传训练和高水平骑士战技
代表性能力:为伤者稳住防线、迅速切入敌阵、借剑枪释放集中的光与斩击；攻击与防护由任务需要决定
限制与代价:治疗不意味着逆转一切伤势，施术与近战都受体力和装备状态影响；剑枪可以折损，不能把耀骑士的名号当成无条件胜利
战斗习惯:辨明应保护的人，先承担最危险的位置；重返卡西米尔后更主动寻求合作，避免把冲锋变成无意义牺牲
</核心设定:临光·能力>

<核心设定:莫斯提马·能力>
定位:范围施术 / 行动节奏控制 / 长途任务支援
武器/战斗方式:配合黑锁与白匙释放不同性质的力量，以范围打击和行动迟滞控制战局
源石技艺/特殊能力:具卓越施术能力，两杖背后的力量与其联系仍有未公开部分；时间相关表现不能简单等同于任意改写历史
代表性能力:压制群体行动、形成强烈范围冲击，必要时提高出力打开战场窗口
限制与代价:高出力会威胁周边设施和友军，必须控制范围；不具无条件回溯、复活或全世界停时权限，两杖的未知部分不自行补成明确神明契约
战斗习惯:观察后从容出手，通常保留余力与解释，不为证明自己强大而扩大破坏
</核心设定:莫斯提马·能力>

<核心设定:史尔特尔·能力>
定位:高热近战 / 突破坚固目标
武器/战斗方式:借随身双手大剑释放难以解析的高热，以直接打击摧毁障碍与目标
源石技艺/特殊能力:主要战斗力量与剑有关，现有检查不能将其归类为常规源石技艺；不把记忆混乱当作力量来源的定论
代表性能力:以剑体引起的高温破坏一般材料，在短暂窗口内进行强力突破
限制与代价:自身基础体质不等于武器威力，极端输出不能无限维持；战斗中的短暂强撑不构成不死。大剑来源、异常显现与记忆之间的关系不明，不据此宣称她就是某位神明
战斗习惯:迅速抓住最直接的突破方式，要求同伴说清目标，不喜欢繁琐而缺少实际价值的指令
</核心设定:史尔特尔·能力>
