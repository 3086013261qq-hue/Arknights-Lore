# CORE-01 验收包 v1.0

状态：构建期源稿完成，待人物精修验收。仅此十人，未开始 CORE-02。

- `characters.md`：10个人物主条目。
- `abilities.md`：10个伴随能力条目，合并异格的阶段变化。
- `pheromones.md`：原创AU全局系统及5个适用个人条目，另列5个不生成的理由。
- `triggers.json`：人物、能力、适用AU共用的关键词及正则，带消歧与阶段约束说明。
- `sources.json`：逐人事实来源、立绘核验与年龄门槛证据。
- `QA.md`：人工审阅、重要阶段差异及验收边界。
- `validation-results.json`、`trigger-validation.json`、`reuse-audit.json`：结构、正则与长串复用检查结果。
- `validate.py`：可重跑的离线源稿验证脚本。

使用时按闭合标签拆为卡内世界书条目；Markdown标题、文件说明与QA不装入角色正文。`triggers.json`是施工映射，不是远程角色加载接口。三个伴随类型使用同一个人物正则，不能用个人名以外的组织名或职业名补触发。

AU默认关闭。开启后，将全局系统和通过年龄门槛的个人条目一并装入卡内；人物关键词本身不确认年龄、不建立关系，也不自动推进阶段。临光个人AU仅适用重返卡西米尔后的明确成年阶段；其他AU亦不适用于未成年回忆。关掉AU应同时停用全局与个人条目。

默认外观以初始立绘为准；卡内当前剧情决定后期经历、身份、装备和能力是否启用。同一人物只保留一张主卡，异格名称只作为别称或阶段，不额外生成主卡。浊心灾难可能性仅可在明确选择的对应分支启用。

没有附带预设修改、远程运行时、第三方卡片或原文镜像。本包不宣称已完成酒馆导入与模型实机测试。

离线复核：在仓库中运行 `python build/character-worldbook/batch_CORE_01/validate.py`。该脚本重新生成结构报告；事实、心理模型和视觉判断仍需结合QA及来源人工验收。
