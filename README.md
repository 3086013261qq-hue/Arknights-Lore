# Arknights-Lore

《明日方舟》咩咩全栈角色卡的独立远程资料仓库。

## 用途

本仓库为角色卡提供轻量、结构化、可按需加载的剧情与设定资源，避免将大型时间线和资料全集直接塞入角色卡本体。

## 核心原则

- 适配咩咩制卡包·全栈与咩咩预设。
- 卡本体保持轻量；大型剧情按篇章拆分后由远程资源层加载。
- 世界书重点维护：时间线、角色、地点、核心设定。
- MVU负责展示与轻交互，不作为剧情唯一事实源。
- 不直接收录或公开搬运外部整合卡、剧情包、小说化文本的原始内容。
- 外部资料仅作为检索、校对与查漏参考；正式资料需重新整理、压缩和改写。

## 目录

- `manifest/`：远程资源索引
- `timeline/main/`：主线时间线
- `timeline/side/`：活动与支线时间线
- `timeline/operator/`：角色个人剧情时间线
- `characters/`：正式角色资料
- `locations/`：正式地点资料
- `settings/`：核心世界设定
- `runtime/`：远程加载与卡侧运行时约定
- `docs/`：施工规范、来源策略与版本文档
- `QA/`：审计与验收记录
