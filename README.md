# Arknights-Lore

《明日方舟》咩咩全栈角色卡的独立远程剧情时间线仓库。

## 用途

本仓库只负责存放体量过大的剧情时间线资源，并通过轻量索引与运行时按需加载，避免将完整主线与大量活动剧情直接塞入角色卡本体。

## 核心原则

- 适配咩咩制卡包·全栈与咩咩预设。
- 远程层只承担剧情时间线，不远程托管角色、地点与核心设定。
- 角色、地点、设定继续作为卡内世界书/资料条目随角色卡发布。
- 剧情按主线、活动/支线、角色个人剧情分块保存并按需加载。
- MVU负责展示与轻交互，不作为剧情唯一事实源。
- 不直接收录或公开搬运外部整合卡、剧情包、小说化文本的原始内容。
- 外部资料仅作为检索、校对与查漏参考；正式时间线需重新整理、压缩和改写。

## 目录

- `manifest/`：剧情远程资源索引
- `timeline/main/`：主线时间线
- `timeline/side/`：活动与支线时间线
- `timeline/operator/`：角色个人剧情时间线
- `runtime/`：剧情远程加载与卡侧运行时约定
- `docs/`：施工规范、来源策略与版本文档
- `QA/`：审计与验收记录

## 非远程内容

以下内容不属于本仓库运行时资源层：

- 正式角色条目
- 正式地点条目
- 核心世界设定

这些内容直接保留在咩咩全栈角色卡本体的世界书中。
