# PRTS 索引镜像层

本目录是《明日方舟》资料重建工程的**构建期索引层**，不作为角色卡运行时世界书，也不直接镜像 PRTS 正文。

## 目标

- 尽可能完整登记 PRTS 中与制卡有关的公开资料入口。
- 只保存事实型索引、名称、分类、页面定位、来源 URL、核验状态等最小信息。
- 角色、地点、组织、国家、种族、核心设定与剧情最终都要重新整理、压缩和改写后再进入正式资料。
- 游戏原文、Wiki 长篇说明、对白、图片、脚本不在此目录整页复制。

## 资料优先级

1. 《明日方舟》游戏内公开资料 / 官方公开资料。
2. PRTS：用于检索、索引、字段核验和剧情定位。
3. 《明日方舟剧本小说》：仅用于主线精确时间顺序、日期和场景衔接辅助校对。

## 目录职责

- `source-manifest.v1.json`：权威索引源入口。
- `catalog/`：从 PRTS 页面抽出的事实型候选清单。
- `qa/`：重复、异格、联动、未实装、名称冲突等核验结果。

## 与正式卡的关系

`reference/prts-index/` 只服务于构建；正式咩咩全栈角色卡仍采用卡内世界书：角色 / 地点 / 核心设定，远程仓库运行时仍只读取 `timeline/` 中的剧情时间线。
